## Urutan baca untuk Fase 1

1. Baca [Keputusan UX Penelaahan Fase 1](keputusan-ux-penelaahan-fase1.md).
2. Baca [Rancangan Analisis–Terima–Ekspor](rancangan-analisis-terima-ekspor.md) untuk keputusan tampilan tanpa setting Word dan perilaku Ekspor.
3. Baca [Rancangan teknis Fase 1](fase1%20drafter.md) untuk detail teknis.
4. Periksa [Kontrak data](kontrak-data.md) sebelum mengubah backend atau frontend.
5. Periksa [Panduan Office.js](panduan-officejs.md) sebelum menggunakan API Word baru.

Dokumen UX terbaru diprioritaskan karena menangkap koreksi langsung dari
penelaah terhadap perilaku produk yang sedang berjalan.
